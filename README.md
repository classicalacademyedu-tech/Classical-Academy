Classical Academy — Netlify starter
Deploy
Extract classical-academy-netlify.zip.
Open Netlify and choose Add new site → Deploy manually.
Drag the extracted folder (the folder containing index.html) into the deploy area.
No build command or publish directory is required.
Included
Responsive Classical Academy welcome/landing page
Course preview section
Login and registration modal UI
Class selector (6–10); group selector appears for class 9 and 10
Forgot-password/reset flow UI
Mobile-friendly navigation
Important production notes
This is a front-end starter/prototype. Login, registration, email OTP, SMS OTP, password reset, database, protected admin/student areas, payments, video hosting and certificates are not connected yet. They require a secure backend (for example Supabase) and configured email/SMS/payment providers. Do not collect real passwords or OTPs with this static demo.
